# Erik Mod Shop — каталог модов

Публичный каталог модов для **Escape From Eric**. Игра и бот читают только этот
репозиторий; сторонние архивы не принимаются.

## Что здесь лежит

```
mods.json        каталог: список модов с хешами и подписями
mods/<id>.zip    архивы модов
schema.json      описание формата
```

## Формат записи в mods.json

```json
{
  "id": "ultra-hard",
  "name": "Ультра сложность",
  "author": "TaNvan_ne_za",
  "version": "1.0.0",
  "game": ">=3.0.1",
  "file": "mods/ultra-hard-1.0.0.zip",
  "size": 1048576,
  "sha256": "…64 hex…",
  "sig": "…base64 RSA-2048…",
  "signed_at": "2026-11-21",
  "tags": ["difficulty"],
  "description": "Одна жизнь, быстрый Эрик, одышка."
}
```

## Правила (кратко)

- никакого контента 18+, шокирующего и оскорбляющего;
- никаких `.exe`, `.dll`, `.bat`, `.ps1` — только контент;
- читы допустимы только те, что не нарушают правила CERBERUS;
- в мультиплеере моды включаются только с согласия игрока;
- в игре с модами отключаются монеты, ставки и защита CERBERUS.

Полные правила — в боте `@titel_support_bot`, команда `/rules`.

## Как попасть в каталог

1. Написать боту `@titel_support_bot` → `/mod`.
2. Пройти правила, приложить архив.
3. Мод проверяется вручную: антивирус, офлайн-тест, проверка расширений.
4. После проверки мод подписывается ключом EM и появляется здесь.

## Подпись

Каждый архив подписывается приватным ключом EM (RSA-2048). Игра проверяет
подпись вшитым публичным ключом и хеш SHA-256. Если подпись не совпала —
мод не устанавливается.
